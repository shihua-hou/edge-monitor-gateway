

## 7. STM32 Bootloader（可选，需要 J-Link）

改了 `firmware_stm32/bootloader/boot_main.c` 和 `EdgeMonitor_Boot/User/main.c`
（两份已同步且代码部分完全一致）。

**只改了 CAN 初始化失败时的处理**：原来是 `while(1)` 死等（= 整机变砖），
现在是打印原因后照常去启动 App。

> **这一步可以不做。** 它修的是"CAN 外设初始化失败"这个从没实际发生过的
> 场景，属于防御性加固；而刷 Bootloader **必须用 J-Link/SWD**——OTA 只更新
> App 区，刷不了 Boot。刷 Boot 的过程本身比它要修的问题风险更高。
>
> 建议：等下次因为别的原因要动 Boot 时顺带一起刷，不为这一条单独操作。

真要刷的话：Keil 打开 `EdgeMonitor_Boot` 编译，J-Link 烧到 `0x08000000`。
烧完**务必先确认板子能正常启动 App**（串口打印 `Boot active slot A` 之后
App 的采集日志正常出现），再做别的事。
